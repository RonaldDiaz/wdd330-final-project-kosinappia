# Kosinappia — Kitchen Units Converter

**WDD330: Web Frontend Development II | Final Project**

Kosinappia is a responsive web application designed to make kitchen measurements easier and more accurate. It allows users to convert ingredients between weight and volume units, explore nutritional information, discover recipes, and save their favorite conversions.

Unlike a conventional unit converter, Kosinappia considers the density of individual ingredients when converting between mass and volume. It integrates external food and recipe data to provide a more informative and interactive cooking experience.

**Live Website:** [Kosinappia](https://wdd330-final-project-kosinappia.onrender.com/)

## Features

### Ingredient Converter

- Convert between common kitchen measurements, including cups, tablespoons, teaspoons, grams, and ounces.
- Browse and filter a catalog of ingredients.
- Retrieve ingredient information from USDA FoodData Central.
- Perform density-based conversions between weight and volume.
- Calculate approximate nutritional values for selected quantities.
- Display practical kitchen measurement equivalents.
- Use preset quantities and swap measurement units.

### Recipe Discovery

- Discover recipes related to the selected ingredient.
- Retrieve recipe recommendations from TheMealDB.
- View recipe details, including ingredients, measurements, and preparation instructions.
- Explore recipes through dynamically generated cards and interactive modal dialogs.

### Personal Cookbook

- Save ingredient conversions for future reference.
- Store conversion details in the browser using `localStorage`.
- View saved conversions and summary statistics.
- Reload previous conversions into the converter.
- Copy conversion results to the clipboard.
- Delete individual items or clear the collection.
- Export saved conversions as a JSON file.

### Ingredient Requests and FAQ

- Submit ingredient information through a request form.
- View a confirmation page containing submitted details.
- Explore frequently asked questions through interactive dialogs.

**Note:** The ingredient request form is a frontend demonstration. It does not submit requests to a backend service or database.

### User Experience

- Responsive layouts for desktop and mobile devices.
- CSS animations, transitions, and interactive hover effects.
- Animated loading indicators and modal entrance effects.
- Accessible semantic HTML and keyboard-friendly controls.
- SEO metadata and social sharing information.

## Third-Party APIs and Attribution

Kosinappia uses two external data providers. Their services make it possible to offer ingredient-specific information and recipe recommendations.

### 1. USDA FoodData Central

**Provider:** United States Department of Agriculture (USDA), Agricultural Research Service

**Official website:** https://fdc.nal.usda.gov/

**API documentation:** https://fdc.nal.usda.gov/api-guide

**Endpoint used:**

```text
GET https://api.nal.usda.gov/fdc/v1/food/{fdcId}
```

**Purpose:**

USDA FoodData Central provides detailed information about food ingredients, including nutritional data and available portion measurements.

Kosinappia processes this information to:

- Retrieve ingredient details using FoodData Central identifiers.
- Obtain nutritional values.
- Examine portion weights and measurement information.
- Support ingredient-specific density calculations.
- Estimate nutritional values for user-selected quantities.

**Attribution:**

Food and nutrient information is provided by **USDA FoodData Central**, a service of the United States Department of Agriculture.

USDA data is used as an external reference source. Calculated conversions and practical kitchen equivalents are generated by Kosinappia and should be considered estimates rather than official USDA conversion recommendations.

**API key:** Access to this endpoint requires an API key.

### 2. TheMealDB

**Provider:** TheMealDB

**Official website:** https://www.themealdb.com/

**API documentation:** https://www.themealdb.com/api.php

**Endpoints used:**

Search for recipes by ingredient:

```text
GET https://www.themealdb.com/api/json/v1/1/filter.php?i={ingredient}
```

Retrieve recipe details:

```text
GET https://www.themealdb.com/api/json/v1/1/lookup.php?i={mealId}
```

**Purpose:**

TheMealDB provides recipe information, including meal names, images, ingredients, measurements, and preparation instructions.

Kosinappia uses this data to:

- Find recipes related to a selected ingredient.
- Generate recipe recommendation cards dynamically.
- Retrieve detailed recipe information when a user selects a meal.
- Display ingredients and cooking instructions in modal dialogs.

**Attribution:**

Recipe information and recipe images are provided by **TheMealDB**. Kosinappia is an educational project and is not affiliated with or endorsed by TheMealDB.

### Main JavaScript Modules

- **`Converter.mjs`** — Coordinates the ingredient converter, user interactions, and dynamic interface updates.
- **`unitConversion.mjs`** — Implements measurement conversions and practical kitchen calculations.
- **`adapters.mjs`** — Transforms external JSON responses into application-friendly data structures.
- **`usdaApi.mjs`** — Handles requests to USDA FoodData Central.
- **`theMealDbApi.mjs`** — Handles recipe searches and detail requests.
- **`Cookbook.mjs`** — Manages the saved conversions interface.
- **`storage.mjs`** — Implements persistent storage, retrieval, deletion, statistics, and JSON export.
- **`Request.mjs`** — Manages the ingredient request interface and FAQ dialogs.
- **`ui.mjs`** — Provides reusable interface utilities.
- **`NotificationManager.js`** — Displays notifications and feedback messages.
- **`data.mjs`** — Contains the predefined ingredient catalog and supporting application data.

## Local Development

### Requirements

- Node.js and npm
- A USDA FoodData Central API key
- An internet connection for external API requests

### Installation

1. Clone the repository and open the project directory.

2. Install the project dependencies:

   ```bash
   npm install
   ```

3. Create a `.env` file in the project root and add your USDA API key:

   ```env
   VITE_USDA_API_KEY=your_usda_api_key_here
   ```

4. Start the Vite development server:

   ```bash
   npm run start
   ```
